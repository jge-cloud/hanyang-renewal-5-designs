후보별 수정 방향

원본 3안과 기존 피그마는 보존했습니다. 기존 정보를 선별·통합한 메인 수정본입니다.

정보의 위치 변경

  • 브로슈어: 큰 표지 섹션을 없애고 모든 후보의 푸터에 PDF 다운로드와 안내 링크를 배치했습니다.
  • 투자·공지·채용: 푸터 보조 링크로 이동했습니다. 기존 재무정보는 준비 중, 공지는 과거 게시물, 채용은 원본 상태를 유지합니다.
  • 기업정보: 사업과 연구·품질 자료로 묶었습니다. 긴 소개와 연혁은 상세 페이지에서 볼 수 있습니다.
  • 제품정보: 소재 → 종류·단면 → 적용 부품의 연결을 후보별 구성에 맞춰 배치했습니다.

문구와 이미지

추상적인 ‘미래의 꿈을 향한 일보전진’ 대신 천연섬유·Plastic·NPS·성형·자동차 내장재라는 기존 자료의 구체적인 용어를 사용했습니다. 성능과 수치는 추가하지 않았습니다.

도로·도어 사진은 적용 맥락을 위한 콘셉트이며 특정 차량 납품의 근거가 아닙니다. 섬유 사진은 실제 제품이 아닌 참고 이미지로 표시했습니다. 실제 부품·사업장 사진은 기존 자료입니다.

교체 권장: 실제 부품 고해상도 원본, 사업장·생산 설비의 최신 사진, 사용 허가된 실제 적용 사진, 최신 브로슈어·인증 상태 확인 자료.
